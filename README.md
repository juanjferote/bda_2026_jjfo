# Prácticas de Big Data Aplicado

Este repositorio contiene las prácticas realizadas durante el curso de especialización en Inteligencia Artificial y Big Data, correspondientes al módulo de Big Data Aplicado.

## Contenido del repositorio

- **UT01:** Prácticas de la primera unidad de trabajo, incluyendo la preparación del repositorio en GitHub.
- **UT02:** Prácticas de la segunda unidad de trabajo, que se incorporarán a medida que avance el curso.

Las prácticas estarán organizadas por unidades de trabajo y cada una contará con su documentación en formato Markdown.
