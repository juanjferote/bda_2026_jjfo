# PR0101: Repositorio en GitHub

## Objetivo

El objetivo de esta práctica es crear y configurar un repositorio Git para organizar y publicar las prácticas del módulo de Big Data Aplicado.

## Tareas realizadas

- Creación del directorio `practicas_bda`.
- Inicialización de un repositorio Git local.
- Creación de la estructura inicial de carpetas para organizar las prácticas.
- Creación de los archivos Markdown para documentar el repositorio y sus unidades de trabajo.
