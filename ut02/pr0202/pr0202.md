# PR0202: Uso del cliente HDFS

## Escenario:
Eres parte de un equipo de análisis de datos que trabaja con Hadoop. Cada usuario tiene su propio espacio en HDFS para almacenar y organizar datasets. Tu tarea es preparar tu espacio, cargar datos de prueba y practicar operaciones básicas de gestión en HDFS.

# 1. Preparación del entorno:
Crea un directorio personal en HDFS bajo /user con tu nombre de usuario y dentro de él un directorio llamado proyecto_datos.
```
hdfs dfs -mkdir /juanjo
```
```
hdfs dfs -mkdir /juanjo/proyecto_datos
```
# 2. Carga de datasets
Desde tu sistema local, sube al directorio proyecto_datos el dataset que has descargado.
(COPIAR AL CONTENEDOR)
```
PS C:\Users\juanj> docker cp "C:\Users\juanj\Desktop\archive\vehicle_price_prediction.csv" namenode:/tmp/vehicle_price_prediction.csv
Successfully copied 127MB (transferred 127MB) to namenode:/tmp/vehicle_price_prediction.csv
```
(CONECTARSE AL CLUSTER HADOOP)
```
PS C:\Users\juanj> docker exec -it namenode bash
```
(COPIAR DEL CONTENEDOR A HDFS)
```
root@namenode:~# hdfs dfs -put /tmp/vehicle_price_prediction.csv /juanjo/proyecto_datos/

# 4. Organización del proyecto
Crea un subdirectorio procesados y otro backup dentro de tu carpeta de proyecto.
```
root@namenode:~# hdfs dfs -mkdir /juanjo/proyecto_datos/procesados
root@namenode:~# hdfs dfs -mkdir /juanjo/proyecto_datos/backup    
root@namenode:~# hdfs dfs -ls /juanjo/proyecto_datos
Found 3 items
drwxr-xr-x   - root supergroup          0 2026-10-27 09:27 /juanjo/proyecto_datos/backup
drwxr-xr-x   - root supergroup          0 2026-10-27 09:26 /juanjo/proyecto_datos/procesados
-rw-r--r--   3 root supergroup  126967327 2026-10-27 09:14 /juanjo/proyecto_datos/vehicle_price_prediction.csv       
root@namenode:~#
```
Copia el archivo original a backup.
```
root@namenode:~# hdfs dfs -cp /juanjo/proyecto_datos/vehicle_price_prediction.csv /juanjo/proyecto_datos/backup/
root@namenode:~# hdfs dfs -ls /juanjo/proyecto_datos/backup
Found 1 items
-rw-r--r--   3 root supergroup  126967327 2026-10-27 09:29 /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
root@namenode:~#
```
Mueve el archivo original de proyecto_datos a procesados.
```
root@namenode:~# hdfs dfs -mv /juanjo/proyecto_datos/vehicle_price_prediction.csv /juanjo/proyecto_datos/procesados/

# 7. Control de accesos
Verifica los permisos de tus archivos.
```
root@namenode:~# hdfs dfs -ls /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
-rw-r--r--   3 root supergroup  126967327 2026-10-27 09:29 /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
```
(EL PROPIETARIO PUEDE LEER Y ESCRIBIR, MIENTRAS QUE EL GRUPO Y OTROS USUARIOS SÓLO PUEDEN LEER EL ARCHIVO)

Cambia los permisos de un archivo de backup para que solo tú tengas acceso de lectura y escritura.
```
root@namenode:~# hdfs dfs -chmod 600 /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
root@namenode:~# hdfs dfs -ls /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
-rw-------   3 root supergroup  126967327 2026-10-27 09:29 /juanjo/proyecto_datos/backup/vehicle_price_prediction.csv
```
(EL PROPIETARIO PUEDE LEER Y ESCRIBIR Y SE LES HAN RETIRADO LOS PERMISOS DE LECTURA A OTROS USUARIOS Y GRUPOS)
